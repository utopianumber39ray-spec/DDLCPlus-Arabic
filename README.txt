# تعريب Doki Doki Literature Club Plus — العربية

حزمة تعريب كاملة لواجهة اللعبة وقصصها (Act 1–3 + Side Stories) إلى العربية الفصحى.

## المتطلبات
- نسخة أصلية من اللعبة على Windows (Steam).
- لا تحتوي الحزمة على اللعبة نفسها، بل ملفات التعريب فقط.

## التثبيت بضغطة واحدة
1. أغلق اللعبة إن كانت تعمل.
2. فك ضغط الحزمة في أي مكان.
3. شغّل `install.bat` (نقرتان).
4. إن لم يجد المثبّت مجلد اللعبة، ألصق مساره:
   `C:\Program Files (x86)\Steam\steamapps\common\Doki Doki Literature Club Plus`
5. شغّل اللعبة، ثم: الإعدادات ← اللغة ← «العربية».

## الإزالة
شغّل `restore.bat` — يعيد كل الملفات الأصلية من نسخة احتياطية أُنشئت عند التثبيت.

## ملاحظات
- لا تُعدّل أي شيء آخر في مجلد اللعبة.
- تعمل مع نسخة Steam الحالية (Windows). لا تُستخدم مع Crack أو نسخة معدّلة مسبقًا.
- إن حدّثت Steam اللعبة فقد يُعاد ضبط التعريب؛ أعد تشغيل `install.bat`.
